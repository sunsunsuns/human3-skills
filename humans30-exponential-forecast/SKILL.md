# 指数外推与进度自检（人类3.0）

> 蒸馏自《人类3.0：不断进步升级的人类》（彼得·诺瓦克，电子工业出版社，2016）第 1 章「进化」。页码 P 为 PDF 页序（P9 = 印刷页 002）。

## R — 原文锚点

> "一般而言，所有技术的指标和性能都每隔 2 年增长 1 倍，而价格会以同样的速度下降。"（P12）

> "他们没有意识到，按照指数级增长的原理，从 1 ％、 100 ％只需要 7 次翻倍。人类基因组项目最终在 2003 年全部完成，比原计划提前了两年。"（P14）

> "从技术角度说，智能手机正处于这个棋盘的中部，这说明真正有意思的东西还没有出现。"（P13–P14）

> "当一个新的技术出现之初，这种技术一般表现不是很好：使用不顺手或者外表没有吸引力，并且十分昂贵。一旦这种技术的外部共生环境发生进化和改善，所有的问题便都迎刃而解。"（P27）

## I — 骨架（机制）

作者的预测能力来自三个可复用的换算，而不是对未来的直觉：

1. **把"年"换算成"翻倍次数"**：摩尔定律（性能约每 2 年翻倍、价格同步下降）意味着任何数字组件的问题都可以问"还差几次翻倍"。7 次翻倍就能从 1% 走到 100%——所以"才完成 10%"往往不是刚起步，而是接近中后段。
2. **把"技术"换算成"组件"**：单个技术不可预测，但它的关键组件（处理器、传感器、存储器、电池）各自沿摩尔曲线上行，因此可以用组件外推法推出"足够好且足够便宜"的年份，再叠加**共生环境**（配套基础设施、用户习惯、内容供给）的成熟时点，取两者较晚者。
3. **把"体验差"换算成"时点未到"**：早期产品丑、贵、难用，多数不是设计失败，而是外部条件未成熟。所以正确动作常常是"押时点"而不是"提前优化"——作者称之为"最核心的问题就是技术的突破，其他的只是时间问题"（P27）。

风险提示（作者自己给的边界）：棋盘类比的"每格翻倍"必须恒定；一旦增长被物理资源约束（米粒总量 90 万亿）或外部条件拉长周期，指数外推就会高估速度。

## A1 — 书中案例（锚点）

- **人类基因组计划**：1990 年立项，预期 15 年；中途进度不足 10% 引发"永远完不成"的恐慌，随后超级计算机与更多人才/资源涌入，进度连续翻倍，2003 年完成，比计划提前 2 年（P14）。
- **数字照相机**：1975 年柯达的史蒂夫·撒森造出又大又贵又丑的原型，按处理器/图像传感器/存储器各自速率推算需 15–20 年才可商业化，1994 年首台上市——距发明 19 年（P27）。
- **苹果 1987 年概念视频**：视频描述 2011 年的场景（平板 + 语音助手），现实中 2011 年 SIRI 发布、次年 iPad 发布（P27）——把"未来硬件水平"当作当期设计约束是可操作的方法。
- **国际象棋米粒**：前 32 格"数量也不是很多"，第 64 格需 90 万亿颗——指数曲线的"前期无感"是判断失误的主要来源（P13）。

## A2 — 触发场景

- 立项论证/融资叙事：要说明"为什么现在做不成的产品，两年后可能只差成本"。
- 研发复盘：团队说"做了两年才 10%"，要判断这是低效还是正常，该加码还是止损。
- 技术选型：自研 vs 等待第三方成熟；要不要按"两年后的硬件"设计产品。
- 硬件/平台创业：给出可辩护的商业化时点区间（而不是拍脑袋的年份）。

**不该调用**：与成本曲线无关的纯组织/管理问题；需要精确财务模型的投资决策（本技能给的是量级与时点区间，不是 NPV）。

## E — 执行步骤

**输入**：技术/产品名称 + 关键组件清单 + 目标用户当前的使用条件 + 项目已耗时与当前完成度。

1. **拆组件**：列出决定这件产品能否成立的关键组件（通常 3–7 个），并标注每个组件当前的性能/价格，以及它是否在稳定翻倍轨道上。
2. **组件外推**：对每个组件估算"达到够用门槛"所需的翻倍次数 n，按 2 年/翻倍折算成年份；取最慢的那个组件作为**技术就绪年份**。
3. **共生环境检查**：配套基础设施、内容供给、用户习惯、法规，各自还需要几年？取**环境就绪年份**。
4. **取较晚者** → 得到一个时点区间（建议给区间而非单点，如"2027–2029"），并标注区间内最可能被打破的假设。
5. **进度自检（7 次翻倍法）**：若项目已完成比例 p，则剩余翻倍次数 n = log2(100/p)。例如 p=10% → 剩约 3.3 次翻倍（约 7 年，若按 2 年/翻倍）；p=1% → 剩约 6.6 次（约 13 年）。用"剩余翻倍次数"替代"完成百分比"做止损判断：
   - if 剩余翻倍次数 ≤ 3 且加速因素（算力/资本/人才）仍在增强 → 应加码而非止损；
   - if 翻倍周期被外部约束拉长（监管、供应链、物理极限）→ 该外推失效，改用线性/里程碑法；
   - if 关键组件不在翻倍轨道上 → 判定为"技术未突破"，等待共生环境无意义。
6. **输出三段**：时点区间 + 剩余翻倍次数与结论（加码/维持/止损）+ 最容易推翻结论的三个假设。

## B — 边界

- **失效条件**：非数字化技术（能源、建筑、医疗审批）的进步速率显著慢于 2 年/翻倍；一旦增长受物理资源上限约束，"翻倍"类比直接失效。
- **不可用于**：对社会/文化变迁的时点预测（作者明确奇点的"准确时点可以留待讨论"，P20）；把科技预测当作承诺来做合同条款。
- **相邻技能分工**：判断"这技术值不值得做"→ `humans30-tech-net-impact`；判断"这个变化是哪股力量"→ `humans30-dual-track-dialectic`；要给议题分领域定位 → `humans30-domain-scan`。
