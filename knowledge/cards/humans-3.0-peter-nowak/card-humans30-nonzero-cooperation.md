# 利他可以扩，但只在"相关性"圈内扩

- **一句话**：合作能否成立取决于三个可查变量——博弈是否重复、是否足够繁荣（有可失去的东西）、对方是否在相关性圈层内；利他半径可经营性扩大，但不会免费扩大。
- **机制**：一次性匿名博弈中背叛占优；重复博弈 + 繁荣 + 互依使合作成为理性解（囚徒困境的现实解）；汉密尔顿法则说明利他按亲缘/相关性分配，资源充足降低竞争压力、连接密度提高使相关性外推——但实验结论仍是"只限于相关的个体"。
- **原文锚点**：`"利他主义应该只限于相关的个体，这个现象可以扩大到一个更广泛的有机体"`（P210）
- **适用场景**：商务谈判、供应链绑定、团队内耗治理、平台生态与开源社区机制设计。
- **失效条件**：一次性匿名交易；局外人（无相关性、无声誉约束、不可持续互动）；非理性/信息严重不对称。
- **可证伪声明**：若在明确的一次性匿名博弈中，普遍出现高成本单方面利他且无任何声誉或后续收益机制，则本原则被削弱。
