# 扫描八领域 + 布拉戈基线 + 四问收敛

- **一句话**：面对开放式技术/社会议题，先定位到 8 个领域（进化/经济/健康/工作/艺术/关系/身份/信仰/幸福），用"山顶洞人布拉戈"算增量，再按"描述→解释→评价→行动"四问收敛。
- **机制**：单一领域视角会只见树木不见森林；宏大叙事须压成可比增量（比火/轮子多做了什么）；四问顺序不可跳（先描述再评价）；3.0 自检 = 是否同时容纳竞争与和谐且自知已不同。
- **原文锚点**：`"本书接下来的章节将试图去量化、测量和对比技术对人类在这个星球上过去一切的影响，进而去探知那究竟意味着什么，希望你能认同人类 3 ， 0 是一个新的、全面进化的物种。"`（P29）
- **适用场景**：行业分析骨架、研究报告讲纲、开放式议题定位与技能路由。
- **失效条件**：八领域是通识分类不是穷尽学科；无决策落点的议题会发散。
- **可证伪声明**：本卡片按 `verifiable: false` 记录（属方法论骨架）；但若八领域之外出现系统性影响维度且无法被现有判据覆盖，则框架应扩充。
