# 收入与幸福：横向成立、纵向不成立

- **一句话**：同一时点富人更快乐，但社会整体变富后平均幸福不升；幸福应按"基线（生理/安全/健康）+ 增量（信任/关系/公平/创造）"分层诊断，先补基线再谈增量。
- **机制**：相对比较 + 收入边际效用递减（伊斯特林悖论，1974）→ 越过基线后加钱的边际收益极低；只有不到一半的幸福内生，其余由环境与应对方式决定；信任是可测量的社会资本（钱包返还率可代理），去摩擦设计会侵蚀它。
- **原文锚点**：`"他的理论以为，在一般意义上，富人比穷人快乐，但当他们的财富增加时，他们并没有变得更幸福，这和收入边际效用递减理论一致。"`（P181）
- **适用场景**：员工/用户满意度诊断、涨薪无效现象解释、福祉项目排优先级、幸福排名可信度尽调。
- **失效条件**：基线未满足的人群收入仍关键；跨文化比较时排名可能测的是"融入社会程度"。
- **可证伪声明**：若某社会在绝对收入普遍翻倍后，其长期生活满意度中位数仍上升超过一个标准差，则伊斯特林式结论在该社会被削弱。
